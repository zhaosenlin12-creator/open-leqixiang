# 乐启享空间剧场大屏重构设计规格

## 目标

把现有卡片式后台页面重构为 16:9 沉浸式数字展厅。默认首屏是全屏混合媒体轮播，固定导航可进入学员、课程、师资、荣誉和机构分类；无人操作时继续轮播，鼠标、触控和键盘均可完成浏览。

## 视觉基准

- 采用用户选定的第三套 `空间剧场` 视觉稿。
- 主色为墨黑、乐启享蓝、明黄、橙色和白色，不使用大面积渐变或装饰性光球。
- 首屏以真实活动照片或视频占据大部分画面，品牌和标题叠加在媒体上。
- 页面使用硬朗直角、细线轨道、层叠抽屉和透视位移，避免仪表盘网格、营销卡片墙和套娃卡片。
- 参考图：`docs/reference/leqixiang-spatial-stage-reference.png`。

## 信息架构

### 首页

- 全屏自动轮播真实图片、视频、课程海报和荣誉素材。
- 顶部常驻 Logo、首页、学员、课程、师资、荣誉、机构导航。
- 右上角提供播放/暂停、静音/有声和全屏按钮。
- 左侧为当前轮播标题、说明和主题标签。
- 底部为序号、进度轨道、上一项、下一项和“探索详情”。
- 任意导航操作退出纯轮播状态；60 秒无操作回到首页并恢复自动播放。

### 学员

- 以横向环形透视画廊展示公开的课堂、项目、活动和团队记录。
- 中央卡片为焦点；两侧卡片按距离缩放、偏移和降低透明度。
- 自动轮换；鼠标悬停、键盘聚焦或触控按下时暂停，离开后恢复。
- 点击卡片打开大幅详情抽屉，包含真实图片、项目主题、能力标签和简短成长描述。
- 未审核附件继续保留在隔离目录，不进入运行时公开素材清单。

### 课程、师资、荣誉、机构

- 分类页沿用空间舞台构图，但使用不同内容编排。
- 课程：横向阶段轨道，点击阶段从右侧逐层展开课程详情。
- 师资：只展示已确认的教研、课堂、项目和竞赛辅导能力，不虚构教师姓名或履历。
- 荣誉：证书和活动成果以展墙方式排列，点击后抽屉放大原图。
- 机构：品牌理念、课程路径、校区环境、联系方式和价格权益以多层抽屉进入。

## 层叠抽屉

- 右侧固定显示三个错位抽屉边缘，当前内容抽屉展开时仍保留后层标签。
- 抽屉支持关闭按钮、遮罩点击、`Escape` 键关闭和左右内容切换。
- 详情以真实媒体为主，文本为辅，不把页面说明或操作教程写进界面。

## 内容与素材

- 品牌 Logo、官网活动图、课程图、证书、PDF 渲染页和营地视频全部从本地 `public/assets` 读取。
- 学员附件包含真实姓名、学校和肖像，按原有 `manual-review` 策略保持未公开；首版使用官网已公开的课堂与活动图形成匿名成长主题。
- 不生成虚假师资、奖项或学员数据，不使用远程 URL 和占位图。
- 所有新增 UI 文案使用正确 UTF-8 中文，旧乱码不再进入可见界面。

## 响应式与可访问性

- 主要验收视口为 1920x1080，同时支持 1366x768 和触控横屏。
- 所有触控目标至少 48px；按钮有 `aria-label`、键盘焦点和可见悬停状态。
- `prefers-reduced-motion` 下停止自动轨道运动并减少大幅动画。
- 图片保留可读裁切，竖版 PDF 使用 `contain`，横版活动照片使用 `cover`。

## 验收标准

- 首页是全屏混合媒体轮播，导航和播放控制真实可用。
- 五个分类均可进入并返回首页。
- 学员环形画廊可自动移动、悬停暂停、手动切换和点击放大。
- 课程、荣誉、师资和机构详情使用层叠抽屉展开。
- 页面无可见乱码、无空白媒体、无静态假按钮。
- `npm test -- --run`、`npm run build` 和 `npm run validate:content` 通过。
- 参考图与 1920x1080 实现截图完成同屏比较，`design-qa.md` 的最终结果为 `passed`。
