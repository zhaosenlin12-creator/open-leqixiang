# 乐启享大屏展示系统设计

## 背景

乐启享需要一个可本地部署到横屏一体机上的触摸大屏展示系统。系统优先服务家长到店咨询转化，同时兼顾活动现场展示、日常公告和自动轮播。大屏应展示机构专业度、荣誉成果、师资能力、学员风采、课程体系、价格权益、特色活动等内容，并能在无人操作时自动进入轮播模式。

当前可用素材包括：

- 官网仓库 `zhaosenlin12-creator/my-website.git`：品牌、课程数据、图片和视频素材。
- 本项目 PDF `乐启享课程规划卡汇总.pdf`：课程卡片、价格权益图、活动海报、奖状模板等。
- 本项目附件 `images/乐启享学员数据库_附件.zip`：学员相关图片，默认不自动公开展示。
- 后续必要时可用 `imagegen` 生成科技教育风格补位素材，但不得伪装成真实师资、真实荣誉或真实学员。

## 目标

第一版交付一个可运行的本地 Web/PWA 大屏应用：

- 兼容 Windows 一体机、安卓一体机和普通浏览器。
- 优先横屏 16:9，覆盖 1920x1080 和 4K。
- 支持触摸操作，按钮和导航适合大屏手指点击。
- 支持分类浏览、一键咨询导览和自动轮播。
- 核心内容和素材本地化，断网仍可展示。
- 第一版用本地文件和配置管理内容，第二版再扩展管理后台。

## 非目标

第一版不做复杂账号系统、云端 CMS、多屏同步、实时官网同步、自动隐私识别、自动生成真实师资履历或真实获奖案例。

## 参考方向

系统借鉴两类产品：

- 数字标牌系统：例如 Anthias、Xibo、Concerto，重点是播放列表、媒体轮播、排期和离线播放。
- 学校/教育机构触摸展厅：重点是可浏览的机构故事、荣誉、课程、照片墙和活动展示。

乐启享大屏采用混合路线：不是通用播放器，而是“机构展示驾驶舱 + 咨询导览 + 分类展厅 + 轮播发布系统”。

## 信息架构

第一版主导航包含 8 个模块：

1. 快速导览：3 分钟快速介绍、8 分钟完整咨询、暑假班专题、竞赛升学路线、价格权益说明。
2. 机构实力：品牌理念、教学体系、校区环境、数据亮点。
3. 课程体系：3-16 岁成长路径，大颗粒、小颗粒、WeDo、Scratch、Python、C++、AI 创赛营。
4. 成果荣誉：赛事地图、奖状模板、优秀作品、后续真实获奖案例入口。
5. 师资团队：第一版展示师资能力模板，不编造姓名和履历。
6. 学员风采：照片墙、作品、成长故事、获奖展示，内容必须人工筛选后启用。
7. 价格权益：公共页展示区间和权益，顾问模式可打开完整价目表素材。
8. 活动公告：海报、视频、PDF 转图、通知、优惠和重要公告。

## 核心交互

默认进入首页驾驶舱。首页包含品牌、关键数据、一键导览入口、8 个分类入口、当前活动和进入轮播按钮。

顾问接待家长时优先使用快速导览。导览路线按预设节点播放，可以暂停、上一页、下一页、跳转详情或返回首页。

家长自助浏览时可以直接点击分类模块。页面层级保持浅，固定提供回首页和进入轮播。

无人操作一段时间后，系统自动进入轮播模式。轮播支持图片、视频、PDF 转图、公告页、课程页、荣誉页等混合内容。触摸屏幕后退出轮播。

## 内容来源和素材策略

官网仓库作为内容和素材来源，不直接复用官网页面。课程结构从官网课程数据迁移整理。图片和视频复制到本地 `public/assets`。

PDF 渲染为本地图片，作为轮播、专题页和价格页素材。竖版海报在横屏中使用居中 contain 展示，并配合品牌背景，不强裁切。

学员附件默认标记为未审核私有素材，不进入展示。只有人工筛选并写入配置后才展示。

生成素材只用于模块封面、科技背景、课程氛围插画等，不作为真实师资、真实荣誉或真实学员照片。

## 技术架构

第一版采用本地 Web/PWA：

- 前端：React + TypeScript + Vite。
- 测试：Vitest，用于内容校验、播放列表、导览和空状态逻辑。
- 内容：`public/content/*.json` 本地配置。
- 素材：`public/assets/**` 本地素材库。
- 导入工具：Node/Python 脚本复制官网素材、渲染 PDF、生成素材清单。
- 离线：PWA service worker 缓存应用 shell、内容配置和核心素材。

主要目录：

- `src/components`：大屏 UI 组件。
- `src/lib`：内容加载、校验、轮播和导览逻辑。
- `src/types`：内容 schema 类型。
- `public/content`：站点、模块、课程、导览、轮播、价格、成果、学员、师资、素材清单。
- `public/assets`：品牌、官网图片、PDF 渲染图、视频和精选素材。
- `scripts`：本地素材导入和校验工具。

## 数据模型

第一版配置文件：

- `site.json`：机构基础信息、联系方式、二维码、默认设置。
- `modules.json`：主模块开关、排序、封面和简介。
- `courses.json`：课程主线、阶段、亮点和代表项目。
- `tours.json`：一键导览路线。
- `playlists.json`：轮播列表和播放项。
- `pricing.json`：公共价格权益和顾问价目表素材。
- `achievements.json`：赛事、荣誉和成果展示。
- `students.json`：人工精选学员风采。
- `staff.json`：师资能力模板和未来真实教师资料结构。
- `assets.json`：素材来源、类型、路径、用途和隐私状态。

素材来源枚举：`website`、`pdf`、`student-archive`、`generated`、`manual`。

## 隐私和真实性边界

- 不自动展示学员姓名、电话、学校等敏感信息。
- 学员内容默认需要人工筛选。
- 不编造真实获奖案例。
- 不编造真实教师姓名和履历。
- 生成图必须作为视觉素材使用。
- 价格页分公共和顾问两种展示层级。

## 验收标准

- 本地运行后可打开首页驾驶舱。
- 可进入 8 个主模块。
- 至少 5 条导览路线可播放、暂停、前后切换。
- 自动轮播可播放图片、视频和原生页面项。
- 课程体系展示来自官网迁移内容。
- PDF 关键页可作为本地素材展示。
- 素材缺失时页面不白屏。
- 断网后已构建内容仍可展示。
- `npm test` 和 `npm run build` 通过。
